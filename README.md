# Research Portfolio (React + Vite)

Static, responsive portfolio website for an academic researcher. Built with React and Vite, suitable for GitHub Pages.

Commands:

- Install: `npm install`
- Local dev: `npm run dev`
- Production build: `npm run build`
- Preview build: `npm run preview`

Notes:

- No server-side logic; all content is static.
- The profile image is embedded directly from Wikimedia Commons and not stored in the repo.
- Update the name, bio, links, and publications in `src/App.jsx`.
